# Claude Code Settings (WYN)

ยังไม่มีการตั้งค่า `.claude/settings.json` หรือ `.claude/settings.local.json` ในโปรเจกต์นี้ ณ วันที่ติดตั้ง WYN AI Company (2026-08-13)

โฟลเดอร์นี้เตรียมไว้สำหรับการตั้งค่าระดับโปรเจกต์ในอนาคต (เช่น permission allowlist, hooks) เมื่อ Founder หรือทีมต้องการกำหนด ไม่ได้สร้าง settings ใด ๆ ไว้ล่วงหน้าเพื่อหลีกเลี่ยงการตั้งค่าที่ขัดแย้งหรือไม่เหมาะสมกับ workflow จริงของทีม

ดู `.claude/agents/` สำหรับ subagent definitions และ `.claude/commands/` สำหรับ custom slash commands (`/product`, `/design`, `/code`, `/qa`, `/debug`, `/deploy`)
