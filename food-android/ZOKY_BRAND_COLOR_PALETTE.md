# Zoky — Official Brand Color Palette

Status: **Brand-design reference, confirmed by user on 2026-10-16**.
Reference: glossy hot-pink Zoky app icon with white round "Zoky" lettering, location-pin-shaped "o", and curved smile.

## Core colors

| Token | Hex | Intended use |
| --- | --- | --- |
| Primary Pink | `#F70365` | Main Zoky brand color |
| Primary Dark | `#CD0244` | Darker buttons, depth and gradients |
| Accent Pink | `#FC4793` | Highlights, glossy shine and accents |
| Soft Pink | `#FCD5EA` | Soft cards and light backgrounds |
| Logo White | `#FDFBFD` | White/pink-white logo and wordmark |
| Deep Magenta | `#AB0230` | Deep gradient, shading and dark accents |

## Additional sampled logo shades

- `#FC207D` vivid hot-pink alternative
- `#E50352` magenta-red midtone
- `#FA96C1` pale pink light reflection
- `#FDECF5` extra-light pink highlight

## Primary gradient

```css
background: linear-gradient(135deg, #FC4793 0%, #F70365 45%, #CD0244 100%);
```

## Design direction

- Mood: **hot pink / magenta, friendly, modern, bright and premium**.
- Keep rounded shapes, clean contrast, subtle highlights and glossy depth from the approved Zoky app icon.
- Use these tokens as the **reference palette** for Zoky Android and Zoky branded media.
- This document **does not alter app styling or enable any deployment**. Platform-specific colors and gradients should be changed only with explicit approval and reviewed for accessible text contrast.
- Distinguish **sampled reference colors** from the currently shipped app UI colors (which may still differ); this is a design decision record, not a claim that every screen has already been updated.
