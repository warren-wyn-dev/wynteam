# WYNOS Quiet Energy Prototype

Interactive, dependency-free UX concept for Founder review. This prototype uses mock data only and does not import, call, or modify any WYNOS frontend, backend, API, database, authentication, or business logic.

## Preview

From the repository root:

```bash
python3 -m http.server 4173 --directory prototypes/wynos-quiet-energy
```

Then open `http://localhost:4173`.

## Included concepts

- Home / Feed
- Profile
- Chat conversation
- Design-system board
- Mobile, tablet, and desktop viewport previews
- Loaded and loading states

## Scope guardrails

- Existing feature vocabulary only
- No Check-in
- No production integration
- No backend, API, database, or business-logic changes
- Prototype assets and data are illustrative only
