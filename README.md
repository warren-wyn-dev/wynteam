# wynteam

Repository สำหรับพัฒนา WYN โดยมี **WYN AI Company** เป็นทีมพัฒนาซอฟต์แวร์ AI ภายในที่ช่วย Founder สร้างผลิตภัณฑ์ WYN อย่างปลอดภัยและตรวจสอบได้

## เริ่มต้นที่นี่

- ทุก AI agent และผู้ร่วมพัฒนา ควรเริ่มอ่านจาก [`AGENTS.md`](./AGENTS.md)
- ภาพรวมองค์กร AI: [`.wyn/company/COMPANY.md`](./.wyn/company/COMPANY.md)
- Workflow การพัฒนา: [`.wyn/company/WORKFLOW.md`](./.wyn/company/WORKFLOW.md)
- สถานะโปรเจกต์ปัจจุบัน: [`.wyn/company/PROJECT_STATUS.md`](./.wyn/company/PROJECT_STATUS.md)
- แนวทางร่วมพัฒนา: [`CONTRIBUTING.md`](./CONTRIBUTING.md)

## สถานะปัจจุบัน

Repository นี้อยู่ในช่วงเริ่มต้น กำลังสร้างโครงสร้างพื้นฐานของ WYN AI Company ก่อนเริ่มพัฒนาฟีเจอร์ผลิตภัณฑ์ WYN จริง (V0.1) ดูรายละเอียดที่ [`.wyn/company/PROJECT_STATUS.md`](./.wyn/company/PROJECT_STATUS.md)
