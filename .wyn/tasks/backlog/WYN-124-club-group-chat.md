# Feature Request — WYN-124

Status: backlog — **ยังไม่ design เต็มรูปแบบตามคำแนะนำ** (ดูเหตุผลใน `.wyn/docs/product/wyn-club-discord-style-roadmap.md`)
Owner: AI Product Manager

Feature: Club Group Chat — แชทกลุ่มเรียลไทม์ภายใน Club (เฟส 2 ของแผน "Club แบบ Discord")

Goal: ให้สมาชิก Club คุยกันสดแบบเรียลไทม์ในห้องเดียวกัน (ต่างจากโพสต์+คอมเมนต์ที่มีอยู่แล้ว/Channels ที่จะมาก่อนหน้านี้ — WYN-123) ตรงกับสิ่งที่ทำให้ Discord "รู้สึกมีชีวิต" ที่สุดตามที่ Founder ระบุ

Target User: สมาชิก Club ที่ต้องการพื้นที่พูดคุยสดแบบไม่เป็นทางการ (ต่างจาก Channel แบบโพสต์ที่ยังมีลักษณะ "ประกาศ/บทความ" อยู่บ้าง)

Problem: ระบบแชทปัจจุบัน (WYN-031) รองรับแค่ 1-ต่อ-1 เท่านั้น — design doc ต้นฉบับของ WYN-031 เขียนไว้ตรงๆ ว่า "ไม่มี group chat... รอบนี้" เป็นการตัดสินใจ scope ที่ตั้งใจไว้ ไม่ใช่ทำไม่ได้ — งานนี้คือการต่อยอด/ขยายกลไกนั้นให้รองรับ N คนต่อห้อง

## ทำไมยังไม่เขียน spec เต็มตอนนี้ (ตัดสินใจร่วมกับ Founder แล้ว)

Founder ตอบชัดผ่าน AskUserQuestion ว่าให้ "วางแผน/design ไว้ก่อน แต่ทำต่อจาก WYN-115-118" — งานนี้เป็นเฟส 2 ต่อจาก WYN-123 (Club Channels) อีกที ระยะห่างจากตอนนี้ถึงตอนเริ่มจริงไกลพอที่จะทำให้ spec ละเอียดที่เขียนวันนี้ (โครงสร้างตาราง, RLS, UI) **ล้าสมัยก่อนได้เริ่มทำจริง** โดยเฉพาะเพราะ WYN-123 เองจะเปลี่ยนโครงสร้าง Club (`club_posts` + `channel_id`) ซึ่งอาจกระทบการออกแบบว่า group chat ควรผูกกับ Club ทั้งก้อนหรือผูกกับ Channel — คำตอบนั้นควรมาจากการดูว่า WYN-123 ลงเอยแบบไหนจริง ไม่ใช่เดาล่วงหน้า

## สิ่งที่รู้แล้วตอนนี้ (บันทึกไว้กันลืม ไม่ใช่ spec)

- ต้องขยายจาก 1-ต่อ-1 เป็น group — ตารางปัจจุบัน (`conversations` เป็น 2-column pair table แบบ `user_a_id`/`user_b_id`) **ใช้กับ group ไม่ได้เลยทั้งโครงสร้าง** ต้องออกแบบใหม่ (junction table แบบ `club_chat_members` ทำนองเดียวกับที่ WYN-031's design doc เคยพิจารณาแล้วปฏิเสธไว้สำหรับ 1-ต่อ-1 เพราะ over-engineer ตอนนั้น — แต่ตอนนี้มี real use case ของ N-people แล้วจริงๆ)
- Unread-count ต่อสมาชิกในกลุ่มใหญ่ซับซ้อนกว่ามาก (WYN-031's `user_a_last_read_at`/`user_b_last_read_at` เป็น 2 คอลัมน์คงที่ ใช้กับ N คนไม่ได้ ต้องมีตาราง read-state แยกต่อสมาชิก)
- Realtime ที่ scale กับสมาชิกจำนวนมากต่อห้อง (Club อาจมีสมาชิกหลักร้อย/พัน) ต่างจาก 1-ต่อ-1 ที่มีคนรับสารแค่คนเดียว
- ควรพิจารณาว่าจะผูกกับ Club ทั้งก้อน (1 Club = 1 ห้องแชทกลุ่ม) หรือผูกกับ Channel แต่ละอันจาก WYN-123 (เช่น "#พูดคุยทั่วไป" กลายเป็นห้องแชทจริง ไม่ใช่แค่โพสต์) — **ตัดสินใจตอนถึงคิวจริง**
