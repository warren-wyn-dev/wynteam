# Feature Request — WYN-092

Status: backlog (ยังไม่เริ่ม — รอหยิบขึ้นมาทำตามลำดับ Phase)
Phase: Phase 2 — UI redesign
แหล่งที่มา: `Wynos V1.0.0 Beta2.pdf` (Founder แนบมาพร้อมคำสั่ง 2026-09-02, ข้อ 14/28) — ดูรายละเอียดคำถาม/คำตอบเพิ่มเติมใน `.wyn/company/DECISIONS.md` (2026-09-02)

Feature: รีดีไซน์การ์ดโพสต์ที่มีรูปภาพหลายรูป (รูปแรกเต็ม รูปที่ 2 โผล่นิดเดียว)
Goal: ให้การ์ดโพสต์หลายรูปสวยขึ้น ชวนกดดูต่อ ตามภาพอ้างอิงของ Founder
Target User: ผู้ใช้ WYN Social ทุกคน
Problem: Founder: "ส่วนรูป อยากได้แบบในรูปเลย เป็นการ์ด รูปแรกเห็นเต็มๆ รูปที่ 2 โผล่นิดเดียว"
Requirements:
- ออกแบบ carousel/stack รูปภาพในการ์ดโพสต์ใหม่ตามภาพอ้างอิง: รูปแรกเต็มความกว้าง รูปถัดไปโผล่ขอบเล็กน้อยเป็น cue ว่ามีรูปเพิ่ม
- รองรับ gesture เลื่อนดูรูปถัดไปในการ์ดเดียวกัน
Acceptance Criteria:
- [ ] โพสต์ที่มีมากกว่า 1 รูป แสดงผลตรงตามภาพอ้างอิง (รูปแรกเต็ม รูปที่ 2 โผล่ขอบ) และเลื่อนดูรูปถัดไปได้
Dependencies: เกี่ยวข้องกับ WYN-091 (restyle การ์ด), WYN-093 (aspect-fit), WYN-103 (limit 9 รูป + บีบอัด)
