# Feature Request — WYN-092

Status: design drafted, pending Founder visual confirmation (2026-09-02)
Phase: Phase 2 — UI redesign
แหล่งที่มา: `Wynos V1.0.0 Beta2.pdf` (Founder แนบมาพร้อมคำสั่ง 2026-09-02, ข้อ 14/28) — ดูรายละเอียดคำถาม/คำตอบเพิ่มเติมใน `.wyn/company/DECISIONS.md` (2026-09-02)

Feature: รีดีไซน์การ์ดโพสต์ที่มีรูปภาพหลายรูป (รูปแรกเต็ม รูปที่ 2 โผล่นิดเดียว)
Goal: ให้การ์ดโพสต์หลายรูปสวยขึ้น ชวนกดดูต่อ ตามภาพอ้างอิงของ Founder
Target User: ผู้ใช้ WYN Social ทุกคน
Problem: Founder: "ส่วนรูป อยากได้แบบในรูปเลย เป็นการ์ด รูปแรกเห็นเต็มๆ รูปที่ 2 โผล่นิดเดียว"
Requirements:
- ออกแบบ carousel/stack รูปภาพในการ์ดโพสต์ใหม่ตามภาพอ้างอิง: รูปแรกเต็มความกว้าง รูปถัดไปโผล่ขอบเล็กน้อยเป็น cue ว่ามีรูปเพิ่ม
- รองรับ gesture เลื่อนดูรูปถัดไปในการ์ดเดียวกัน
Acceptance Criteria:
- [ ] โพสต์ที่มีมากกว่า 1 รูป แสดงผลตรงตามภาพอ้างอิง (รูปแรกเต็ม รูปที่ 2 โผล่ขอบ) และเลื่อนดูรูปถัดไปได้
Dependencies: เกี่ยวข้องกับ WYN-091 (restyle การ์ด), WYN-093 (aspect-fit), WYN-103 (limit 9 รูป + บีบอัด)
Priority: กลาง
Risks:
| # | ความเสี่ยง | ระดับ | การป้องกัน |
|---|---|---|---|
| R1 | โครงสร้าง carousel ใหม่กระทบ performance การโหลดรูปในฟีด (โหลดหลายรูปพร้อมกัน) | กลาง | lazy-load เฉพาะรูปที่กำลังจะเห็น |
Recommendation: อนุมัติ ส่งต่อ AI Design ทำ spec ภาพก่อน
Handoff: AI Design (แปลงภาพอ้างอิงเป็น spec) → AI Coding

## Design Output (2026-09-02)

Founder แนบภาพอ้างอิงมากับ PDF ต้นฉบับที่ session นี้ไม่มีไฟล์ — ออกแบบ draft จากคำพูด Founder ("รูปแรกเต็มๆ รูปที่ 2 โผล่นิดเดียว") + design system เดิม: peek strip กว้างประมาณ 24-32px (ค่าตั้งต้น draft 28px) โผล่ขอบขวาของการ์ด, swipe เพื่อดูรูปถัดไปในการ์ดเดียวกันโดยไม่ต้องเปิด Detail, ยังใช้ตัวนับ "N/M" แบบเดียวกับที่มีอยู่แล้วใน `DropDetailScreen`'s `DropImageGallery` เพื่อความสม่ำเสมอ — ตั้งใจ**ไม่แตะ** `DropImageGallery`/`DropDetailScreen` เลย (เป็นคนละ pattern ที่อนุมัติแล้วสำหรับหน้ารายละเอียด) พบ data gap ที่ต้องปิดก่อนด้วย: `HomeFeedItem` ยังไม่มี field จำนวนรูป (มีแค่ใน `Drop` model) ต้องเพิ่มก่อนถึงจะขึ้นโค้ดจริงได้

Design doc เต็ม: `.wyn/docs/design/wyn-092-multi-image-card-peek.md`

**Blocked**: รอ Founder ยืนยัน peek width/สไตล์เทียบกับภาพต้นฉบับก่อนส่ง AI Coding
