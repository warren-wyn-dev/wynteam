# Feature Request — WYN-091

Status: design drafted — badge text change ready for coding, card restyle pending Founder visual confirmation (2026-09-02)
Phase: Phase 2 — UI redesign
แหล่งที่มา: `Wynos V1.0.0 Beta2.pdf` (Founder แนบมาพร้อมคำสั่ง 2026-09-02, ข้อ 13/28) — ดูรายละเอียดคำถาม/คำตอบเพิ่มเติมใน `.wyn/company/DECISIONS.md` (2026-09-02)

Feature: รีสไตล์การ์ดโพสต์แบบข้อความล้วนในหน้า Home ให้เรียบหรูขึ้น + แก้ข้อความ badge โพสต์ใหม่
Goal: หน้า Home อ่านง่ายขึ้น สวยขึ้นสำหรับโพสต์ที่เป็นข้อความล้วน และ badge แจ้งโพสต์ใหม่ไม่ต้องระบุจำนวน
Target User: ผู้ใช้ WYN Social ทุกคน
Problem: Founder: "หน้า Home feed อยากให้เรียงโพสต์ที่เป็นข้อความแบบนี้ เรียบๆหรู เหมือนในรูป" + "ปล. วงน้ำเงินที่เขียนว่า 'มีโพสต์ใหม่ 3 โพสต์' เปลี่ยนเป็น 'มีโพสต์ใหม่' จะขึ้นมาเฉพาะ มีโพสต์ใหม่ๆ"
Requirements:
- ออกแบบการ์ดโพสต์ข้อความล้วนใหม่ตามภาพอ้างอิงของ Founder (เรียบ, หรู, เว้นระยะอ่านง่าย)
- เปลี่ยนข้อความปุ่ม/badge "มีโพสต์ใหม่ N โพสต์" เป็น "มีโพสต์ใหม่" แบบไม่ระบุจำนวน — badge ขึ้นเฉพาะตอนมีโพสต์ใหม่จริงเท่านั้น (ไม่ใช่ค้างอยู่ตลอด)
Acceptance Criteria:
- [ ] โพสต์ข้อความล้วนในหน้า Home มีสไตล์ใหม่ตรงภาพอ้างอิง
- [ ] badge โพสต์ใหม่ขึ้นข้อความ "มีโพสต์ใหม่" ไม่มีตัวเลข และขึ้นเฉพาะตอนมีโพสต์ใหม่จริง
Dependencies: เกี่ยวข้องกับ WYN-086 (ลำดับข้อความ/รูป) และ WYN-092 (การ์ดรูปภาพ)
Priority: กลาง
Risks:
| # | ความเสี่ยง | ระดับ | การป้องกัน |
|---|---|---|---|
| R1 | เปลี่ยน layout การ์ดแล้วกระทบการ์ดโพสต์ที่มีทั้งข้อความและรูปด้วย | ต่ำ-กลาง | แยก component ให้ชัดระหว่างการ์ดข้อความล้วน vs การ์ดมีรูป |
Recommendation: อนุมัติ ส่งต่อ AI Design ทำ spec ภาพก่อน
Handoff: AI Design (แปลงภาพอ้างอิงเป็น spec) → AI Coding

## Design Output (2026-09-02)

แยกเป็น 2 ส่วน: (1) Badge — ตรวจโค้ดพบว่าเงื่อนไข "ขึ้นเฉพาะตอนมีโพสต์ใหม่จริง" ถูก implement ถูกต้องอยู่แล้ว (`_newPostCount > 0`) เหลือแค่ตัดตัวเลขออกจากข้อความ ("มีโพสต์ใหม่ N โพสต์" → "มีโพสต์ใหม่") — ไม่ต้องรอภาพ พร้อมขึ้นโค้ดทันที (2) การ์ดข้อความล้วน "เรียบ หรู" — Founder แนบภาพอ้างอิงมากับ PDF ต้นฉบับที่ session นี้ไม่มีไฟล์ ออกแบบ draft จากคำพูด Founder + design system เดิม (เพิ่ม padding + เส้นคั่น hairline ใต้ข้อความ ไม่เพิ่มกรอบ/สี/เงาใหม่) **ต้องรอ Founder ยืนยันเทียบกับภาพต้นฉบับก่อนส่ง AI Coding**
