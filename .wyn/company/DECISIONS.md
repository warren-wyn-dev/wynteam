# Founder Decisions

## 2026-09-12 — Chat system visual direction / Profile layout lock

Founder approved the chat-system UI direction shown in the 2026-09-12 WYNOS chat mockup: minimal white/paper surfaces, Ink/black primary actions, quiet neutral metadata, rounded search/input surfaces, compact pill filters, clean chat bubbles, and consistent bottom-sheet / media-viewer presentation across every existing chat surface.

Scope applies to the existing chat system only: 1:1 Inbox, Conversation, New Message, Message Requests, Share to Chat / share sheet, View Once / chat media surfaces, message actions / composer states, and existing Club group chat surfaces. Existing behavior and safety actions must remain available; the mockup is a visual/layout reference and must not be used to invent unsupported chat capabilities.

Founder explicitly locked the current Profile layout: do not redesign or change Profile UI/layout as part of chat-system work. Profile may only be changed later if Founder explicitly requests it.
