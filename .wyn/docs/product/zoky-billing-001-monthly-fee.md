## 1. สถานะปัจจุบัน (ตรวจโค้ด 2026-10-27)

- **GP v1** (`supabase/migrations/20261011140000_merchant_gp_v1.sql`):
  - Super admin ตั้งอัตรา GP รายร้านได้ เก็บเป็นประวัติ
  - ค่าเริ่มต้นคือ 0% ทุกร้าน
  - เก็บผ่าน Stripe application fee เท่านั้น ออเดอร์จ่ายด้วยสลิปจึงเก็บ GP ไม่ได้
- **Stripe ถูกพักไว้:** ลูกค้าและร้านจ่ายด้วยการโอนพร้อมสลิปเท่านั้น
- **ระงับร้านมีอยู่แล้ว:** Admin ระงับร้านได้ด้วย `food_stores.admin_suspended_at` และ Merchant app แสดงแบนเนอร์ "ร้านถูกระงับ"
- **ระบบสลิปมีแบบอย่างแล้ว:**
  - สลิปค่าโฆษณาของร้านเก็บใน bucket ส่วนตัว แยกโฟลเดอร์ตามร้าน และ Admin เป็นคนตรวจ (`food_ad_topups`)
  - สลิปคืนเงินใช้แบบเดียวกัน
- **ยังไม่มี:** แพ็กเกจรายเดือน ใบแจ้งหนี้ บัญชีรับเงินของ Zoky และการแจ้งเตือนค้างจ่าย

## 2. Requirements

### P0 Admin: ตั้งค่าแพ็กเกจ
1. Admin ตั้ง**ค่าบริการรายเดือน (บาท)** และ**จำนวนวันทดลองใช้ฟรี**ได้ บันทึกเป็นประวัติ ไม่แก้ทับของเดิม
   - ราคาใหม่มีผลกับรอบบิล**ถัดไป** ไม่เปลี่ยนใบแจ้งหนี้ที่ออกไปแล้ว
2. Admin ตั้ง**บัญชีรับเงินของ Zoky** (PromptPay หรือบัญชีธนาคาร พร้อมชื่อบัญชี) ที่ร้านเห็นในใบแจ้งหนี้
3. สิทธิ์: เฉพาะ Admin ที่มีสิทธิ์การเงินร้านค้าแบบแก้ไขได้ ตรวจฝั่ง server ทุกครั้ง

### P0 ใบแจ้งหนี้
4. ระบบออกใบแจ้งหนี้ให้ร้านที่เปิดขาย**เดือนละ 1 ใบ** มีรอบเดือน ยอดเงิน และวันครบกำหนด
   - ยอดเงินมาจากราคาในระบบ server คำนวณเอง ไม่รับยอดจากเครื่องร้าน
   - ร้านที่ยังอยู่ในช่วงทดลองใช้ไม่ต้องจ่าย
5. สถานะใบแจ้งหนี้: `unpaid → slip_submitted → paid` หรือ `rejected` (ส่งสลิปใหม่ได้)
   - Admin ยกเว้นค่าบริการรายใบได้ (`waived`) โดยต้องใส่เหตุผล

### P0 Merchant: จ่ายค่าบริการ
6. เจ้าของร้านเห็นใบแจ้งหนี้ ยอดเงิน วันครบกำหนด และบัญชีรับเงินของ Zoky ใน Merchant app
7. เจ้าของร้านแนบสลิปได้ ตรวจชนิดไฟล์ ขนาด และเนื้อหาเหมือนสลิปเดิม
   - เก็บใน bucket ส่วนตัว โฟลเดอร์ `billing/<store_id>/<invoice_id>/`
   - เฉพาะ owner/admin ของร้านนั้นอัปโหลดได้
   - ร้านอื่นและลูกค้าเห็นสลิปไม่ได้

### P0 Admin: ตรวจสลิป
8. Admin เห็นรายการใบแจ้งหนี้ที่รอตรวจ เปิดสลิป แล้วกดยืนยันหรือปฏิเสธพร้อมเหตุผล
   - บันทึกว่าใครกดและเมื่อไร (audit)
9. Admin เห็นรายการร้านค้างจ่าย: ยอด และจำนวนวันที่เลยกำหนด

### P0 ค้างจ่าย
10. แจ้งเตือนเจ้าของร้านใน Merchant app (และ push ถ้าเปิดไว้) ก่อนครบกำหนด วันครบกำหนด และหลังเลยกำหนด
11. **ระบบไม่ระงับร้านเอง** Admin เป็นคนกดระงับ โดยใช้การระงับร้านที่มีอยู่แล้ว เมื่อร้านจ่ายแล้ว Admin เป็นคนกดยกเลิกการระงับ

### P0 GP
12. ใช้ค่าบริการรายเดือน**แทน** GP: ทุกร้านอยู่ที่ GP 0% ต่อไป
    - ประวัติ GP เดิมและตัวเลข GP ในรายงานเก่ายังเก็บไว้
    - ส่วนจะซ่อนหรือปิดหน้าตั้งค่า GP ใน Admin หรือไม่ ดูคำถามข้อ Q6

### Out of scope
- Stripe และการตัดบัตรอัตโนมัติ
- ระงับร้านอัตโนมัติ
- หลายแพ็กเกจ หรือราคาต่างกันรายร้าน (ถ้าต้องการ ต้องตัดสินใจใหม่)
- ใบกำกับภาษี (ดูคำถามข้อ Q5)

## 4. Acceptance criteria (ร่าง)

- Admin ตั้งราคาและช่วงทดลองใช้ได้ ราคาใหม่ไม่เปลี่ยนใบแจ้งหนี้ที่ออกไปแล้ว
- ทุกร้านที่เปิดขายและพ้นช่วงทดลองใช้ได้ใบแจ้งหนี้เดือนละใบเท่านั้น (ห้ามซ้ำ)
- ร้านแนบสลิปได้เฉพาะใบแจ้งหนี้ของร้านตัวเอง การยิง API ตรงด้วยร้านอื่นต้องถูกปฏิเสธ
- Admin ยืนยันหรือปฏิเสธได้ พร้อม audit และร้านได้รับแจ้งผล
- ร้านค้างจ่ายได้รับแจ้งเตือนตามตาราง และระบบไม่ระงับร้านเอง
- GP ทุกร้านยังเป็น 0% และรายงานเก่าไม่เปลี่ยน
- ทดสอบสิทธิ์ข้ามร้าน การยิง API ตรง สลิปปลอมหรือไฟล์ผิดชนิด และใบแจ้งหนี้ซ้ำ
