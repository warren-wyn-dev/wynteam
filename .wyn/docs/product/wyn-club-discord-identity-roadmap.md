# WYN Club — ทำไมยังไม่รู้สึกเหมือน Discord และควรเพิ่มอะไร (2026-09-06)

> ตอบคำถาม Founder: "ควรเพิ่มฟีเจอร์อะไรเข้าไปเพิ่ม ในคลับ ยังดูไม่คล้ายดิสเลย"
> อ้างอิงต้นฉบับ: `.wyn/docs/product/wyn-club-founder-brief.md` ("ต่อยอดในอนาคตไปสู่: ... Club Chat ...")

## สถานะปัจจุบันของ Club (สร้างไปแล้วจริง)

Club ตอนนี้มี: สร้าง/เข้าร่วม Club (Public/Private), Club Page (Cover/Icon/สมาชิก/Join), Posts feed เดียว (Text/รูป/Poll — WYN-115), Members tab (role badge Owner/Admin/Moderator/Member), About tab (กฎ Club), Pin Post, Admin system (approve/remove/ban), Discovery+Search, Home integration, Notification เมื่อมีโพสต์ใหม่/ปักหมุด (WYN-116), Owner Insights (WYN-117), **Events** (WYN-118 — สร้าง/RSVP กิจกรรม), เชิญเพื่อนเข้า Club ผ่าน Followers (WYN-123/124)

พูดสั้นๆ: Club วันนี้คือ **"Facebook Group ที่มี Poll/Events"** — ครบเรื่อง "โพสต์+จัดการสมาชิก" แต่ยังไม่มีแกนที่ทำให้ Discord รู้สึกเป็น Discord เลย

## แกนของ Discord ที่ WYN Club ยังไม่มี (เรียงตามน้ำหนักที่คนรู้สึกได้ทันที)

1. **Channel หลายห้องในคอมมูนิตี้เดียว** — Discord ไม่มี "feed เดียว" มันมี #general, #announcements, #ถามตอบ, #แชร์ผลงาน แยกกันชัดเจน ผู้ใช้เลือกอ่านเฉพาะเรื่องที่สนใจได้ Club ของ WYN วันนี้โยนทุกอย่าง (คุย, ประกาศ, ถามตอบ) ลง feed เดียวหมด — **นี่คือจุดที่คนรู้สึกว่า "ไม่เหมือน Discord" เร็วที่สุด**
2. **การพูดคุยสด (real-time chat) ไม่ใช่แค่โพสต์** — Discord คือห้องแชทที่มีคนพิมพ์ตอบกันสดๆ ต่อเนื่อง ไม่ใช่ฟีดที่โพสต์แล้วรอคนมา like/comment ทีหลังแบบ async — WYN มีระบบแชท 1-ต่อ-1 อยู่แล้ว (WYN-031/032/033) แต่ยังไม่มี "กลุ่มแชท" เลยแม้แต่จุดเดียวในระบบ
3. **Role ที่มีสีสัน/ปรับแต่งได้** — Discord ให้เจ้าของ server สร้าง role เอง ตั้งชื่อ ตั้งสีเอง (เช่น "🎨 Artist", "VIP") ติดป้ายสีข้างชื่อสมาชิกทุกที่ที่เห็น ส่วน WYN Club ตอนนี้มี role ตายตัวแค่ 4 ระดับ (Owner/Admin/Moderator/Member) ใช้ระบบสิทธิ์ล้วนๆ ไม่มีมิติ "แสดงตัวตน/สถานะพิเศษ" ในกลุ่มเลย
4. **ความรู้สึกว่า "มีคนอยู่ตอนนี้"** — Discord โชว์จุดเขียวออนไลน์ + "X คนออนไลน์" ตลอดเวลา ทำให้ server รู้สึกมีชีวิต WYN Club ไม่มีสัญญาณ real-time ใดๆ เลยว่าตอนนี้ใครอยู่บ้าง

## สิ่งที่ตั้งใจไม่แนะนำตอนนี้ (และทำไม)

- **Voice/Video Channel** — เป็นเอกลักษณ์ที่สุดของ Discord แต่เป็นการลงทุนโครงสร้างพื้นฐานคนละระดับเลย (WebRTC/SFU server, ค่า bandwidth ต่อเนื่อง, ทีม infra เฉพาะทาง) ไม่เหมาะกับแอป Beta ที่เพิ่งมีผู้ใช้จริงกลุ่มแรก ควรพิสูจน์ว่า text-based community ติดตลาดก่อน ค่อยกลับมาพิจารณา
- **Bot/Automod แบบ custom command** — ต้องมี permission model ของ "bot account" ทั้งระบบใหม่ ยังไม่คุ้มกับขนาดคอมมูนิตี้วันนี้
