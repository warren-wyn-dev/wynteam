## Deploy รอบที่ 2 — 2026-09-05 09:29–09:37 UTC (แก้บั๊ก carousel ที่ Founder เจอหลัง deploy รอบแรก)

Founder เปิด `wynos.online` ดูจริงแล้วส่งคลิปหน้าจอมา พบ 2 บั๊กใน WYN-111 (carousel) ที่ deploy
รอบแรกยังไม่เจอ:

1. **"เห็นสีขาว ตรงรูปแรกไหม"** — `Transform.scale` (ที่ใช้ทำให้รูปตรงกลางขยายใหญ่) ย่อรูป peek เข้าหา
   จุดกึ่งกลางของตัวมันเองแบบ default ทำให้เกิดช่องว่างสีขาวระหว่างรูปหลักกับรูปที่ peek แทนที่จะแนบชิด
   กันเหมือนเดิม — ยืนยันด้วยการดึงเฟรมจากคลิปมาดูจริง เห็นช่องขาวชัดเจนทั้งสองฝั่ง
2. **"รูปสุดท้าย ควรเลื่อน จนสุดเป็นสีขาว"** — โค้ดล็อก physics เป็น `ClampingScrollPhysics` (แบบ Android
   หยุดสนิท) ในทุก platform ทั้งที่ doc comment เดิมในไฟล์เขียนไว้ว่าตั้งใจให้ "bounce บน iOS" อยู่แล้ว
   (โค้ดไม่ตรงกับ comment ของตัวเอง) ทำให้ลากเลยรูปสุดท้ายไม่เด้งเผยพื้นขาวแบบ Threads

แก้ทั้งสองจุดใน `app/lib/core/widgets/post_media.dart` เท่านั้น (ไม่แตะ stride/snap logic เดิม):
- เปลี่ยน `Transform.scale`'s alignment ให้ยึดขอบที่ติดกับรูปหลัก (ไม่ใช่ center) ตามตำแหน่ง scroll จริง
- เปลี่ยน physics parent จาก `ClampingScrollPhysics` เป็น `BouncingScrollPhysics`
